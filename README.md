# JF Stone & Build website

**Live website:** [jfstoneandbuild.pages.dev](https://jfstoneandbuild.pages.dev/)

A responsive website for JF Stone & Build, a small construction business serving South Cumbria, Carnforth, Lancaster and the South Lakes. The site is built with HTML, CSS and JavaScript, with AI-assisted coding. I’m a beginner Python learner and career changer from construction, using practical projects to build software skills.

## What it includes

- Service information, project gallery and before-and-after photographs.
- Mobile navigation and responsive image sizes.
- Direct phone and email links, plus an enquiry form handled by FormSubmit.
- Privacy information and an enquiry confirmation page.
- Keyboard-accessible navigation and image gallery controls.

## Run locally

From the repository root, run `python -m http.server 8765 --bind 127.0.0.1` and open `http://127.0.0.1:8765/`. The site is static and has no build step or package dependencies.

## Hosting and enquiry form

The site is hosted on Cloudflare Pages. FormSubmit may require recipient activation; email delivery should be considered verified only after a real submission is received in the intended inbox. Phone and email links are also available on the site.
